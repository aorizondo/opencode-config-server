# Corporate engineering standards

Three references, read the one that applies:

- `references/coding-standards.md` — typing, documentation, testing and linting
  requirements per language.
- `references/git-workflow.md` — branch naming, commit format, pull request and
  review rules.
- `references/security-policies.md` — credential handling, dependency policy and
  what must never reach a repository.

When a project's own AGENTS.md or CLAUDE.md contradicts these, the project wins:
it is closer to the code. Say so explicitly instead of silently picking one.
